Issues Found and Fixed
Root Cause Analysis
#IssueRoot CauseFixStatus
1 selfTokenWebClient bean not found — OTP service failed to start kernel-auth-adapter was documented in the README as a manual step for authentication-otp-service/pom.xml but was never actually added to the file. Without the JAR on the classpath, BeanConfig from the adapter was never loaded. Added kernel-auth-adapter dependency to authentication-otp-service/pom.xml Fixed
2 503 LoadBalancer error at OTP service startup — "LoadBalancer does not contain an instance for the service localhost" Spring Cloud LoadBalancer intercepts all outbound HTTP calls made through a @LoadBalanced WebClient. It extracts the host from the URL and treats it as a service-registry name. Since localhost is not registered, it returns 503. This is triggered by MasterDataCacheInitializer calling http://localhost:8082/v1/masterdata/title at startup. Added spring.cloud.loadbalancer.enabled=false to bootstrap.properties for both services. This disables the LoadBalancer so calls to localhost go directly to WireMock. Fixed
3 ModuleNotFoundError: No module named 'pkg_resources' in sample client dynaconf==3.1.9 imports pkg_resources from setuptools, which is no longer bundled with Python 3.12+ / 3.14. Upgraded dynaconf to 3.2.4 in requirements.txt Fixed
